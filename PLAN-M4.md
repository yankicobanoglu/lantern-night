# M4 plan — Sound, sharing, install

Scope from SPEC.md section 10: Web Audio soundscape, share image, offline support, install hints, persistent-storage request, accessibility pass. Budget about €15. Builds on M3 without changing the ritual or the pixel rules.

## Accept when

1. Works offline after the first load (Playwright: load, wait for the service worker, go offline, reload, the scene boots).
2. The share image renders correctly (1080×1920 PNG, the scene at an integer upscale, the wordmark, optionally the wish in a soft panel; checked by decoding the produced file in the test).
3. A keyboard-only run and a reduced-motion run complete the whole ritual.

## Out of scope (deliberately)

- Adaptive quality, session light arc, timing polish, README, deploy (M5).
- Haze merging, seated figure (P1).

## Decisions

**Audio (`src/audio/`).** Everything is generated with Web Audio, no files. `AudioEngine` owns one `AudioContext`, created on the first user gesture (pointerdown or keydown on the document, capture phase) and resumed on every later gesture until it runs, which is what iOS needs. Master gain sits at −18 dB and fades in over 2 s. The ambient bed is filtered noise for wind (a low-pass whose cutoff and gain drift on slow LFOs), sparse cricket chirp trains (a high sine gated by short envelopes, scheduled a few seconds ahead), and occasional water lapping (band-passed noise bursts). Lighting is a noise whoosh whose band-pass cutoff and gain follow the hold fill. Release is a bell (four inharmonic partials with exponential decays) on a random note from C5 D5 E5 G5 A5. The shooting star is a faint shimmer (a small cluster of high sines sliding down). Sound off means the master gain goes to 0 and the bed stops; the context stays. Hidden tabs suspend the context.

**Mute toggle.** A 44 px button in the top-right corner, visible in every state and over every overlay, with `aria-pressed` and the labels "Sound on" / "Sound off" (not in the copy deck; proposed below). It writes `settings.sound`, the same value the Settings switch uses, and both stay in sync.

**Share (`src/share/`).** "Share my sky" opens a small sheet with a preview of the image, the "Include my wish" switch (default off; only offered when there is a wish to include) and the share button. The image is composed offscreen: a second `Scene` is built for a fixed 180×320 art px layout (6× is exactly 1080×1920), fed the current moon frame, sky lights and rising lanterns, rendered once into a 1080×1920 render texture (pixel world and light layer), then drawn onto a 2D canvas with the wordmark in Pixelify Sans at the bottom and, when asked, the wish text in a section 7 panel. Web Share with a file where `canShare` allows, otherwise a download named `lantern-night-YYYY-MM-DD.png`. The sheet is reachable from the watch state (the released lantern's wish) and from Your sky (the selected light's wish). `window.__lantern.shareImage(wish?)` exposes the composed PNG to tests so it can be decoded and measured.

**Offline (`vite-plugin-pwa`, section 8).** `registerType: 'autoUpdate'`, precache of every built file plus the fonts, `navigateFallback` to the app's `index.html` under `BASE`. The manifest is generated by the plugin with `start_url` and `scope` relative to the base, `display: 'standalone'`, night as theme and background colour. Icons are pixel art drawn in code: `scripts/make-icons.mjs` renders a hand-authored lantern map to PNG (a small PNG encoder over Node's zlib; no dependency) at 180, 192 and 512 px, into `public/icons/`. `index.html` gains the Apple meta tags and the touch icon.

**Install hints.** Detection in `src/ui/install.ts`: iOS/iPadOS Safari not installed when `navigator.standalone === false` (iPadOS reports a Mac UA, so touch points are checked too); other browsers when `beforeinstallprompt` fires (kept for the Install button). The hint shows on the first visit right after the first lantern has risen (when the watch buttons come in), then once more on the third visit if still not installed; `installHintCount` records both. `?install=ios|prompt` forces a path in tests.

**Persistent storage.** After the first lantern is saved, `navigator.storage.persist()` is called once (only while `persistGranted` is null) and the result is recorded.

**Accessibility.** Every screen moves focus to its first control when it appears, and the goodnight veil is focusable and reacts to Enter/Space, so the whole ritual runs on a keyboard. Escape closes the menu, the overlays and the share sheet. The tap alternatives already exist; the mute button, share sheet and install hint are real buttons with labels. `prefers-reduced-motion` is respected end to end (Playwright `reducedMotion: 'reduce'`).

**Test hooks.** `window.__lantern` gains `audio()` (`{ started, running, muted }`), `shareImage()` (data URL of the composed PNG, test only) and `install()` (the detected path and the hint count).

## Steps

1. Audio engine, ambient bed, cues, mute toggle, settings wiring. Unit tests for the helpers.
2. Share: compose, share/download, sheet, watch + Your sky entry points. E2E decoding the PNG.
3. PWA: plugin, manifest, icons script, Apple tags. E2E offline.
4. Install hints and persistent storage. Unit tests for the schedule.
5. Accessibility pass: focus, keyboard, Escape. E2E keyboard-only and reduced motion.
6. Screenshots, bundle size, full suites in both browsers, commit "M4: sound, sharing, install". Record results below.

## Result (2026-09-17)

- Unit: 71 Vitest tests pass (14 new: sound helpers, install detection and the hint schedule). End-to-end: 172 test runs across the four projects, 77 passing on Chromium phone/desktop and 73 on WebKit phone/desktop with the rest project-specific skips (desktop-only perf checks, the WebKit offline reload), the M1–M3 suites unchanged; the offline spec was split into a cache check and the reload after that run, and reruns of it pass on every project. New specs: `offline.spec.ts` (manifest and icons under the base path, every loaded file in the worker's cache, offline reload, no foreign requests), `share.spec.ts` (1080×1920 PNG measured for the night sky, the moon, the wordmark and the wish panel; the sheet from Your sky with the download path; the sheet from the watch state), `access.spec.ts` (keyboard-only ritual with Escape, reduced-motion run, audio after the first tap and the mute toggle, install hint on visits 1 and 3, persistent storage). Screenshots and the real share PNG in `e2e/output/`.
- Bundle: main JS 104.6 KB gzipped (+6.0 KB over M3 for audio, share and the worker registration), workbox-window 2.2 KB, CSS 3.4 KB. Precache 28 entries, 692 KB.
- Headless notes: Chromium creates and runs the AudioContext on the Begin click (`{started:true, running:true}`); `navigator.storage.persist()` is supported and returns false in headless Chromium, so the setting records `false`. WebKit's Tab skips buttons unless Option is held (Safari default; the test presses Option+Tab there). Playwright's WebKit throws an internal error on a reload while offline with a controlling worker, so the offline reload runs on Chromium only and the WebKit projects check the cache contents instead; the airplane-mode check on the iPhone (section 11) covers Safari for real.
- Icons are generated by `node scripts/make-icons.mjs` from a 16×16 hand-authored map into `public/icons/` (the PNGs are committed so the build needs no extra step).
- Deviations and proposals for review:
  - Mute toggle labels "Sound on" / "Sound off" (aria labels, no visible text) are not in the copy deck.
  - "Share my sky" opens a small sheet (preview, "Include my wish", the button, Close) rather than sharing at once, so the toggle has a place to live. The opener and the confirming button share the label.
  - The goodnight veil is a focusable control labelled "Back to the start" so the ritual can end from the keyboard.
  - The install hint panel has a Close button (the deck has no dismiss line); the iOS line also goes on its own after 16 s.
- Not verifiable headless, for the iPhone check: how the soundscape actually sounds (levels are at −18 dB master, wind 0.42, crickets 0.045, water ~0.13, whoosh up to 0.55, chime 0.42, shimmer 0.16 before the master), the real share sheet, Add to Home Screen, airplane mode, and whether persist() is granted after installing.
